# 运动生理文献库

这是一个面向人体运动、训练表现与运动生理研究的文献网页。页面保留英文题名、中文题名、期刊、DOI、原文入口和中文摘要；默认按本站首次收录日期显示。

## 当前维护规则（唯一有效流程）

1. **只有主维护端写入仓库。** 外部 AI、协作人或检索工具只提交候选清单和来源依据，不创建分支、不提交 PR、不改数据库、不改网页文件。
2. **先确认，后录入。** 每条候选文献须由维护者确认纳入；确认后才由主维护端以受控增量方式写入。
3. **只增量追加。** 每次发布只能新增经确认的 PMID/DOI；不得删除、合并、重排既有题录，不得对全库重新抓取或重建页面。
4. **保留基线。** `catalog.sqlite.gz` 与 `dist/index.html` 是已发布基线。禁止直接用抓取脚本、历史贡献或批量回填覆盖它们。
5. **中文内容。** 中文标题与摘要应忠实表达原始英文信息；术语优先采用运动生理学、运动训练学、体育科学和运动医学的常用译法，不增加原文未支持的结论。
6. **发布前校验。** 新增记录必须核验 PMID、DOI、英文题名、期刊与原始摘要；不得有重复 PMID、空中文摘要或编码错误。发布后还应核验网页总记录数只按新增数量变化。
7. **可追溯发布。** 每批确认记录保存在 `approved-records/`，发布结果写入 `.publication-log/`；GitHub Pages 仅从 `dist/` 发布。

## 提交候选清单给主维护端

请以表格或清单提供：PMID、DOI、英文题名、中文题名、期刊、文献类型/主题及 PubMed 或出版社链接。可以说明推荐理由和不确定性，但不要向本仓库推送任何文件。

## 维护者可调整的配置

| 目标 | 位置 |
| --- | --- |
| 期刊和 ISSN | `journals.txt` |
| 数据源 | `sources.json` |
| 纳入范围 | `screening.py` |
| 专题分类 | `presentation.py` |
| 术语规范 | `exercise_glossary.json` |
| 页面外观与交互 | `site-src/` |

变更上述配置前，必须先在独立分支核验，不能以此触发对已发布基线的全量覆盖。

## 故障恢复

`archive-state` 仅作为历史恢复点；恢复必须先核验记录总数、中文题名/摘要数量和页面版式，再由主维护端执行。自动全量抓取、历史贡献合并和批量摘要回填均已停用，避免再次缩减或覆盖网站内容。
