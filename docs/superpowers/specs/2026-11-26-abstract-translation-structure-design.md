# 摘要翻译结构设计

## 目标

保留英文摘要作为翻译输入，但网站正文只展示中文摘要；按 PMID/DOI 管理翻译任务，避免标题改写造成错配。

## 数据结构

论文记录支持 `abstract_en` 与 `abstract_zh`。翻译状态由字段是否为空推导：缺少英文摘要为“无摘要原文”，有英文摘要但无中文摘要为“待翻译”，两者均有为“已完成”。

## 导出与回填

`export_abstract_queue.py` 导出 Markdown 表格，包含 PMID、DOI、英文标题、中文标题、期刊、英文摘要和空白中文摘要列。回填程序按 PMID 优先、DOI 其次匹配，不覆盖英文原文。

## 网页

静态数据只包含 `abstract_zh`，不把 `abstract_en` 输出到页面；有中文摘要时显示摘要区域，无中文摘要时显示待翻译状态。
