# 审核论文类型建议

网页上“类型待确认 · 建议分类”会打开预填 DOI、英文题名和建议类型的 GitHub Issue；提交者需自行确认提交，维护者核对官网或索引来源。

审核通过后，以小写 DOI 为键，将确认的类别写入仓库根目录的 `article_type_overrides.json`。值必须是页面中的文献类型（不能是“类型待确认”），例如：

```json
{"10.1234/example": "原创研究"}
```

通过 Pull Request 审核并合并后，GitHub Actions 重建网站，修改将影响所有访问者。没有 DOI 但有 PMID 的论文也可以提交，使用 `pmid:12345678` 作为键。没有 DOI 和 PMID 的论文暂不支持此入口；不要使用标题作为唯一标识。不要直接把未经核实的 Issue 内容写入配置。
