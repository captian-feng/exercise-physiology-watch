# 运动生理文献库 · 录入原则

> 用途：交给 AI 或其他协作者，在批量筛选文献时按统一标准判断。
> 本文件与站点实际运行规则（`screening.py`、`article_types.py`）保持一致。
> 版本：2026-11-23

---

## 一、一句话定义

**收录「以人为对象、以运动为刺激或情境、并报告生理学或运动表现结果」的原创研究。**

三个条件必须同时满足，缺一不可。

---

## 二、三条必要条件（全部满足才收录）

### 条件 1：研究对象是人

**必须**来源于人体数据：

- 运动员、体育爱好者、健康成人、儿童青少年、老年人
- 军人、职业人群等有运动暴露的人群

**排除**：

- 小鼠、大鼠、猪、马、斑马鱼等任何动物
- 离体细胞、肌管、类器官、离体肌肉、培养组织
- 尸体、力学模型、计算机仿真（无活体人体数据）
- 数据库二次分析中**不含人体运动测量**的模拟研究

### 条件 2：存在运动刺激或运动情境

满足以下**任一**：

| 类型 | 举例 |
|---|---|
| 训练干预 | 抗阻训练、耐力训练、HIIT/SIT、冲刺训练、爆发力/增强式训练、并发训练、血流限制训练、离心训练、周期化训练 |
| 运动方案比较 | 不同强度/量/频率/间歇方式的对照 |
| 急性运动试验 | 力竭测试、递增负荷测试、时间试验、Wingate 测试 |
| 运动人群观察 | 赛季监测、训练负荷追踪、运动员横向比较 |
| 体能测试与评估 | 体能测试、运动表现测量、生理指标测试 |

### 条件 3：报告生理学或运动表现结果

必须报告以下**任一类**可量化指标：

- **心肺代谢**：VO₂max/峰值摄氧量、氧摄取动力学、心率、乳酸阈、临界功率、能量消耗、底物氧化
- **神经肌肉**：力量、功率、肌电(EMG)、力矩、发力率、肌纤维募集、肌肉厚度/横截面积
- **运动表现**：冲刺速度、跳跃高度、时间试验成绩、耐力表现、变向能力
- **生物力学**：运动学、动力学、地面反作用力、关节力矩
- **环境生理**：核心体温、出汗率、水合状态、热适应
- **血管自主神经**：血压、血流、动脉僵硬度、心率变异性、自主神经调节
- **体成分**：体脂、瘦体重、骨密度
- **生化指标**：运动后血液标志物（仅当与运动干预直接关联）

## 三、必须排除的类型

### 3.1 学科不符

| 类型 | 判定 |
|---|---|
| 纯心理学 | 动机、焦虑、倦怠、自我效能、心理韧性、心理疲劳、正念、自我对话 |
| 社会科学 / 教练研究 | 教练行为、领导力、职业发展、运动员身份、社会学调查 |
| 问卷 / 质性研究 | 以问卷、访谈、焦点小组为主要方法 |
| 流行病学 / 公共卫生 | 以人口统计为主，无运动干预或生理测量 |
| 生物传感器 / 算法开发 | 以传感器、机器学习模型、算法为主要贡献 |
| 单纯体能测试方法学 | 以量表/测试协议验证为主要目的 |

### 3.2 层级不符（纯微观研究）

排除**没有整体生理测量**的：

- 基因、多态性、遗传关联研究
- 转录组、蛋白组、代谢组、单细胞测序
- 细胞培养、离体实验、分子通路、信号传导
- 动物模型机制研究

> **例外**：若标题或摘要含分子/心理词汇，但**同时报告了整体测量**（如 VO₂max、肌肉力量、心率），则保留。

### 3.3 人群不符

排除**疾病人群**研究（非运动人群）：

- 癌症、心衰、糖尿病、多发性硬化、帕金森、阿尔茨海默
- 肥胖/超重儿童（非运动员）
- 术后康复、透析、器官移植患者

> **例外**：研究对象若是**运动员**，即使涉及疾病也收录（如运动员心脏筛查）。

### 3.4 文献类型不符

排除：

- 社论、评论、读者来信、勘误、撤稿通知
- 会议摘要、海报、论文集（除非明确要求）
- 预印本（优先等待正式发表版本）
- 研究方案/注册（除非明确要求）
- 指南、共识声明、立场文件（除非明确要求）

> 若需要收录综述，见第五节分类标准。

## 四、边界情况的判断规则

### 4.1 优先看摘要，不只看标题

标题常不完整。例如：

- 「Biceps femoris motor unit discharge rates」→ 标题无测量指标，但摘要报告了运动表现 → **收录**
- 「Effects of training on anxiety」→ 有训练但结果为心理量 → **排除**

**判断顺序**：标题 → 摘要 → 期刊类型 → 文献类型。

### 4.2 训练方法本身就是研究对象

只要是**运动训练相关研究**，即使标题未写测量指标，也**收录**。训练刺激本身即运动生理学的研究事件。

举例（均应收录）：

- Cluster vs. rest-redistribution set configurations
- Lower-leg inclination and Nordic hamstring exercise efficacy
- Determination of swimming training intensity zones
- Resistance Training for Cyclists: Scientific Evidence

### 4.3 拿不准时的原则

- **倾向收录**：明确是人体运动 + 有生理/表现测量
- **倾向排除**：主要贡献是心理/社会/传感器/分子机制
- **绝不强行归类**：无法判断时标记「待确认」，不要猜测

## 五、文献类型分类标准

收录后需标注类型，取值仅限以下 7 种：

| 类型 | 判定标准 |
|---|---|
| **原创研究** | 一手数据，人体受试者，报告结果 |
| **系统综述与证据整合** | 系统综述、meta 分析、范围综述、叙述性综述 |
| **会议摘要、海报与会议论文** | 补充期（issue 含 S/sup/Suppl）且单页或无页码 |
| **综述以外的评论** | 社论、评论、读者来信、勘误 |
| **方案与注册** | 研究方案、试验注册 |
| **指南、共识与立场文件** | 临床指南、专家共识、立场声明 |
| **类型待确认** | 无法确定时使用，**不要猜测** |

> 注意：PubMed 标记「Journal Article」**不等于**原创研究，必须核对摘要。

### 6.2 刊外文献

非上述期刊的文献，仅在**完全符合第二、三节**时可收录，需注明来源期刊。

### 6.3 不建议扩充的期刊类型

- 综合医学刊（Cureus、Medicine、PLOS ONE、BMJ Open）：噪声率 >90%
- 公卫/流行病学刊（BMC Public Health、Frontiers in Public Health）
- 专科刊（麻醉、口腔、肿瘤支持治疗、兽医）

## 七、输出格式（提交给维护者时使用）

每篇必须提供以下字段，缺失的跳过：

```
标题（原文）:
期刊:
发表日期:
DOI:
PMID:
文献类型: （从第五节选）
判定结果: 收录 / 排除 / 待确认
符合条件: （列出第二节哪几条 + 第四节哪条边界规则）
一句话依据: （研究做了什么运动干预、测了什么指标）
摘要片段: （支撑判断的关键句，≤200字）
```

### 提交前的自检清单

- [ ] 研究对象是人，且非疾病人群
- [ ] 有明确运动刺激或运动情境
- [ ] 报告了可量化的生理或表现指标
- [ ] 不是纯粹的心理/社会/传感器/分子研究
- [ ] DOI 或 PMID 至少有一个
- [ ] 文献类型标注正确（未把综述当原创研究）

## 八、常见误判示例

| 标题 | 正确判定 | 理由 |
|---|---|---|
| Resistance training and muscle hypertrophy in older men | 收录 | 人体 + 训练 + 肌肉量 |
| Exercise and depression: a meta-analysis | 收录（综述类） | 人体运动 + 心理结局，但类型为系统综述 |
| Effects of HIIT on anxiety in college students | 排除 | 结局为心理量 |
| ACTN3 genotype and sprint performance | 待确认 | 有运动表现，但主要是遗传关联 |
| Exercise serum and AMPK in C2C12 myotubes | 排除 | 细胞实验 |
| Cardiac screening in elite footballers | 收录 | 运动员人群，属运动医学 |
| HIIT in patients with heart failure | 排除 | 疾病人群 |
| Coach leadership and athlete burnout | 排除 | 社科/心理 |
| Wearable sensor algorithm for fatigue detection | 排除 | 算法开发为主 |
| Six weeks of respiratory training on sprint performance | 收录 | 人体 + 训练 + 表现，即使涉及焦虑 |
| Nordic hamstring exercise efficacy | 收录 | 训练方法即研究对象（4.2 条） |

## 九、给 AI 的执行要点

1. **先判条件 2（运动刺激）**，这是最快的排除条件。无运动则直接排除。
2. **再判条件 1（人体）**，检查摘要是否明确出现人类受试者、样本量、人群描述。
3. **最后判条件 3（生理结果）**，确认有可量化指标。
4. **遇到边界情况**，优先查摘要而非标题，并在输出中注明判断依据。
5. **不确定就标「待确认」**，绝不猜测，维护者会复核。
6. **不要因为期刊不在列表就排除**，刊外文献符合条件也收。
7. **不要因为期刊在列表就自动收录**，仍需判断条件 1-3。
